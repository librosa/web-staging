librosa.frames_to_time

librosa.frames_to_time(frames, *, sr=22050, hop_length=512, n_fft=None)[source]

Convert frame counts to time (seconds).

Parameters:
framesnp.ndarray [shape=(n,)]

frame index or vector of frame indices

srnumber > 0 [scalar]

audio sampling rate

hop_lengthint > 0 [scalar]

number of samples between successive frames

n_fftNone or int > 0 [scalar]

Optional: length of the FFT window. If given, time conversion will include an offset of n_fft // 2 to counteract windowing effects when using a non-centered STFT.

Returns:
timesnp.ndarray [shape=(n,)]

time (in seconds) of each given frame number:

times[i] = frames[i] * hop_length / sr

See also

time_to_frames

convert time values to frame indices

frames_to_samples

convert frame indices to sample indices

Examples

>>> y, sr = librosa.load(librosa.ex('choice'))
>>> tempo, beats = librosa.beat.beat_track(y=y, sr=sr)
>>> beat_times = librosa.frames_to_time(beats, sr=sr)
